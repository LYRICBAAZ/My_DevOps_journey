# 🚀 90 Days of DevOps

> **Learn → Practice → Build → Document → Repeat 🔥**

Welcome to my **90 Days of DevOps Challenge**.

This repository is my day-by-day journey to learn **DevOps through hands-on practice, exercises, automation, cloud technologies, and real-world projects**.

I will document everything I learn throughout these 90 days — including **notes, commands, configurations, exercises, projects, screenshots, errors, and key takeaways**.
